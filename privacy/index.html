1. Overview

Booblyc TD is a tower-defense game, the sequel to the "Incursion" series. This page covers the browser (HTML5) version, which you play directly on a game portal's website — it is not downloaded from an app store and does not create an account with us.

Booblyc is a small independent game team; the person responsible for this game and for this policy is Fedir Danylov.

The short version: the game itself collects almost nothing. Your save data lives in your browser and, if you choose to sync it, in the portal's cloud storage. Ads and payments are entirely run by the website you're playing on, using a shared plugin called Playgama Bridge — I never see your payment details, and the game does not run any tracking or analytics SDKs of its own on the web.

2. What data is stored, and where

Game save (local)

Your progress — levels completed, cards, gems, settings — is saved as a file in your browser's own local storage for the game's page, the same way any browser game keeps your progress between visits. It never leaves your device unless cloud sync (below) is available and enabled by the portal.

Game save (cloud copy, via the portal)

If the portal you're playing on supports cloud storage, a copy of your save file is uploaded to that portal's storage a few seconds after you save, under one fixed key. At the next launch, if that cloud copy is more advanced than what's on your device, it replaces your local save. This lets your progress follow you if you play the same game on the same portal from a different browser or device, as long as the portal recognizes you (e.g. because you're logged into the portal).

This save data is game state only — cards, levels, in-game currency, settings. It is not an account profile, and it does not knowingly include your name, email, or other personal details.

Anonymous player ID

The game generates a random 16-character ID (not tied to your name, email, device ID, or any account) and stores it in your save file. It is used only if you redeem a promo code — see Promo codes — to prevent the same code being reused, and otherwise only travels inside your save file (including the portal's cloud copy described above).

Downloaded game files (cache)

The game downloads its art, sound and level files in stages as you play, and your browser caches them so a returning visit doesn't re-download everything. This is a technical cache of game assets, not personal data, and is cleared the same way as any other browser cache.

3. The hosting portal & Playgama Bridge

The game loads one shared plugin, Playgama Bridge, which in turn connects to the actual website you're playing on (for example Playgama itself, CrazyGames, Poki, GameDistribution, MSN, or another site in that network). Through this bridge, the portal — not the game, and not me as the developer — handles:

  • Advertising — which ads are shown, to whom, and any ad-related tracking or personalization. This follows the portal's own ad policy and consent settings, not the game's.
  • Payments — processing any in-game purchase you make. The game only ever receives a product ID and an order ID confirming what you bought; it never sees your card number, billing address, or other payment details.
  • Cloud save storage — described above.
  • Basic session info — your rough platform/language settings, and simple "game loaded / level completed / level failed" signals the game sends the portal for its own ranking and store-listing purposes. These do not carry any player identifier.

Because the exact portal depends on where you're playing, please also check the privacy policy of the website where you play the game (usually linked in its footer). A few portals' policies, where I could confirm a working link:

  • Playgama — playgama.com/confidential
  • CrazyGames — crazygames.com/privacy-policy
  • GameDistribution — static.gamedistribution.com/policy/privacy-enduser.html
  • MSN / Microsoft — microsoft.com/en-us/privacy/privacystatement
  • Poki, and any other site not listed above — see the privacy policy linked in the footer of that website.

4. Promo codes

If you choose to type a promo code into the game, the code you entered and your anonymous player ID (see above) are sent to a small backend script I run (hosted on Google Apps Script) that checks the code and marks it as used. This only happens when you actively enter a code — never automatically. Like any web request, the script's host inherently sees the IP address the request came from; the game itself does not send your IP, device, or account information beyond the code and the anonymous ID.

5. Purchases

All in-game purchases on the web version are handled by the portal's own payment provider through Playgama Bridge, using whatever payment methods that portal supports. I never see or store your card details or billing information — only a confirmation that an order was made (an order ID and the product you bought), so the game can grant it. Refunds, billing questions and payment-method changes need to go through the portal or its payment provider, not through me.

6. What we do not collect on the web version

Several tracking and analytics services exist in the mobile app version of this game but are deliberately switched off in the browser version — they don't load, and they don't send anything:

The browser version does not ask for your name, email address, real identity, precise location, contacts, microphone, camera, or any device permissions beyond what your browser already grants any website.

7. Cookies & local storage

The game itself does not set tracking cookies. It uses your browser's local storage to keep your save file and cached game files, as described above. The website hosting the game (the portal) may set its own cookies for login, preferences, ads or analytics — that is covered by the portal's own privacy/cookie policy, not this one.

8. Children's privacy

Booblyc TD is a general-audience game, and some of the portals that host it have audiences that include children. The game itself does not knowingly collect personal information from anyone, including children — it does not ask for a name, email, birthdate or any account details. Ads shown while playing are selected and served by the hosting portal, following that portal's own rules for child-directed advertising (for example, non-personalized ads where required by law). If you believe a child has provided personal information through this game in a way that concerns you, please contact us using the email below and we will help however we can.

9. Your rights (GDPR, UK GDPR, CCPA and similar laws)

Depending on where you live, you may have rights over the limited data described in this policy — mainly your save data and the anonymous player ID. In plain terms, you can ask to:

  • Know what's stored — this page already describes it in full; there's no hidden profile beyond your save file.
  • Delete it — see How to delete your data below.
  • Object or withdraw — since nothing here is used for profiling or targeted advertising by me directly, this mainly means simply not using the cloud-save or promo-code features.
  • Not be discriminated against for exercising any of these rights (relevant under CCPA/CPRA) — the game works the same whether or not you use cloud save or promo codes.

Because the game keeps no account and no contact information tied to your save data, I generally cannot look up "your" data from a name or email — data requests are handled by clearing your local browser storage and/or the portal deleting its stored copy, as described below. For anything ads- or payments-related, those rights are best exercised with the portal directly, since that data lives with them, not with me.

10. Data retention

  • Local save & cache: kept in your browser until you clear it, uninstall/reset the browser, or it's cleared automatically by the browser (e.g. low storage).
  • Cloud save copy: kept by the portal for as long as your portal account (or equivalent) exists, or until overwritten by a newer save, or deleted per the portal's own retention policy.
  • Promo code requests: the backend keeps the codes themselves and, for single-use codes, a note that a code was used and by which anonymous player ID.

11. How to delete your data

  1. Local save: use your browser's "Clear site data" / "Clear browsing data" for the portal's site (or just this game's page, if your browser allows per-site clearing). This removes your local save and cached game files instantly — note this also resets your local progress.
  2. Cloud save copy: if the portal offers account/data deletion tools, those will remove the stored copy. Otherwise, contact us at the email below and we'll help you get it removed, or contact the portal directly.
  3. Anything else: email booblyc.support@gmail.com and describe what you'd like removed — we'll respond as soon as we can.

12. Changes to this policy

If this policy changes, the updated version will be posted here with a new effective date at the top. Since the game keeps no contact list, we can't email you about changes directly — please check back occasionally if you'd like to stay informed.
